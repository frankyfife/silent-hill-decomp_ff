# Qt launcher

Game options, level select and Play. The C# launcher (`pc_port/launcher`) stays
for the Mod Manager, asset tools and updates; **Mods & Tools...** opens it.

- Options are data: one entry in `src/Options.h` per config key.
- `config.cfg` is edited in place: only changed keys are rewritten, everything
  else (comments, order, unknown keys, binds) passes through.
- **Level Select** starts the game with `-map <id> -spawn <s> -difficulty <d>`,
  which the game applies for that session only (`pc_port/src/pc_level_select.c`).
  The map and spawn lists come from `resources/level_select.json`, generated by
  `pc_port/tools/gen_level_select.py` from the same tables the game reads -- rerun
  it when `src/map_registry.c` or `include/pc_rando_data.h` change.
- The launcher finds `SilentHillPC.exe` next to itself or one folder up, so it can
  live in a subfolder with its Qt DLLs.

## Build (Windows, MSVC + Qt 6)

The game builds with MinGW, this launcher with MSVC (the installed Qt kit), so it
is its own CMake project. From a "x64 Native Tools" prompt:

```
cmake -G Ninja -S pc_port/launcher_qt -B pc_port/launcher_qt/build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=D:/Qt/6.8.3/msvc2022_64
cmake --build pc_port/launcher_qt/build
```

Deploy into a subfolder of the game, e.g. `<game>/QtLauncher/`:

```
windeployqt --release --no-translations --no-system-d3d-compiler --no-opengl-sw --no-network <game>/QtLauncher/SilentHillPC_LauncherQt.exe
```
